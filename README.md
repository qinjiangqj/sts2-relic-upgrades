# 杀戮尖塔 2 · 遗物升级

遗物升级 v0.114.0.3 对应《杀戮尖塔 2》v0.114.0，适用于单人标准模式，需要 BaseLib v3.4.8。源码在 `src`，图标 PNG 在 `art`。

Mod 版本号采用 `游戏版本.更新序号`。同一游戏版本下从 `.1` 开始，后续更新依次使用 `.2`、`.3`。适配新游戏版本时，更新前三段并从 `.1` 重新计数。游戏清单采用加载器支持的格式，例如 `0.113.1-1` 对应 Mod `v0.113.1.1`。

把构建产物中的整个 `RelicForge` 文件夹放入游戏安装目录的 `mods`。更新旧版时一起替换 DLL、JSON 和 PCK。重新启动游戏，在 Mod 设置中启用 BaseLib 和「遗物升级 / Relic Upgrades」。

## 升级规则

- 普通战斗胜利掉 0～1 个碎片，精英掉 1～2 个，第一、第二幕 Boss 掉 2～3 个。两个数量等概率。碎片和金币一样在「搜刮」中点击领取，跳过时放弃未领取的碎片。
- 在火堆选择「升级遗物」，可从网格中挑一件遗物。按「查看升级后」可切换整组图标。选定后可并排比较两种形态的图标与效果。确认升级消耗 4 个碎片和本次火堆行动。
- 第一、第二幕 Boss 胜利后，进入下一幕，在先古回血并选好祝福后点击继续，会获得一次免费升级机会。可以跳过。
- 171 件遗物各有一个升级形态和专用图标。每次升级都会用新形态替换原遗物。磨刀石等 144 件保留原版效果。
- 初始遗物可走本 Mod 的升级路线，或选择奥罗巴斯之触的原版升级。两条路线互斥，界面会在确认前提示。

## 重新构建

安装 .NET 9 SDK 后，在此目录运行 `./build.ps1`。脚本通过 Steam 库定位游戏和 BaseLib，也可以显式指定路径。

```powershell
./build.ps1 -GameDir $gameDir -BaseLibDir $baseLibDir
```

将 `$gameDir` 和 `$baseLibDir` 设为游戏和 BaseLib 的安装目录。构建产物在 `Mod/RelicForge`，首次构建会一并生成 `RelicForge.pck`。

更换图标时，把透明 PNG 放进 `art/small` 和 `art/detail`。文件名使用原遗物 ID 的小写，例如 `anchor.png`。每件遗物的两种尺寸见 `art/IconLayout.json`。运行 `./tools/Pack-Art.ps1 -GameDir $gameDir` 重新生成 `RelicForge.pck`。
